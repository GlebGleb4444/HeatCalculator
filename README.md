# Heat Calculator (Розрахунок кількості теплоти)

## Про програму
Програма з графічним інтерфейсом (Windows Forms, C++/CLI) розраховує кількість теплоти, необхідну для нагрівання або охолодження речовини, за формулою:

**Q = m · c · (T2 − T1)**

Де:
* **Q** — кількість теплоти (Дж);
* **m** — маса речовини (кг);
* **c** — питома теплоємність (Дж/(кг·°C));
* **T1, T2** — початкова та кінцева температури (°C).

Програма також визначає характер процесу: нагрівання (Q > 0), охолодження (Q < 0) або відсутність теплообміну (Q = 0).

## Як запустити
1. Відкрийте файл рішення `HeatCalculator.slnx` (або `.sln`) у Visual Studio.
2. Натисніть **F5** (або Ctrl+F5) для запуску.
*(Потрібен .NET Framework та підтримка C++/CLI)*.

## Як користуватися
1. Виберіть речовину зі списку (питома теплоємність `c` підставиться автоматично).
2. Введіть масу `m`, початкову `T1` та кінцеву `T2` температури.
3. Натисніть **«Розрахувати»**.
4. У блоці результатів з'являться: `ΔT`, `Q` (у Дж та кДж) та характер процесу.
5. Кнопка **«Очистити»** скидає всі поля.

## Структура проєкту
* `MyForm.h` — графічний інтерфейс (дизайн форми) та логіка обробників подій (кнопки, введення).
* `MyForm.cpp` — точка входу (`main()`), запуск програми.
* `HeatModel.h` — опис класу моделі (поля `m, c, T1, T2, DeltaT, Q, ProcessStatus` та оголошення методів).
* `HeatCalculator.cpp` — реалізація методів моделі (`Validate()` для перевірки даних та `Calculate()` для обчислень).
